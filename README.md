# Personal Expense Tracker
A simple, lightweight web application to track personal expenses. Built with **Node.js**, **Express**, and **EJS** for server-side rendering. No database required (in-memory storage for quick prototyping), making it easy to run and understand.
Perfect for learning full-stack basics or as a starting point for a more advanced finance tool.
## Features

Add expenses with description, amount, and category
View all expenses in a clean, responsive table
Automatic running total calculation
Delete individual expenses
Date stamping for each entry
Simple, modern UI with Tailwind-inspired CSS (no external frameworks needed)

# Tech Stack

**Backend**: Node.js + Express
**Templating**: EJS (Embedded JavaScript)
**Frontend**: HTML + CSS (vanilla, with clean responsive design)
**Storage**: In-memory array (easy to extend to JSON file or MongoDB later)
